Scroll World Specification

Scroll World is an agent skill for Claude Code, Codex, and any SKILL.md-compatible agent. It orchestrates AI diorama generators (GPT Image via Higgsfield) and camera-flight video models (Seedance 2.0 / Kling 3.0 via Monid / Higgsfield) with seamless frame-locked seams.

1. Install as Claude Code Plugin

/plugin marketplace add oso95/scroll-world
/plugin install scroll-world@scroll-world

2. Install with Vercel Skills CLI (Codex / Cursor / 20+ agents)

npx skills add oso95/scroll-world

3. Deploy this Repository to Vercel
